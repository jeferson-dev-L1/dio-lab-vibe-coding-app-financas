# 💸 App de Organização de Finanças Pessoais Conversacional com Design Universal

Este projeto foi desenvolvido como um Desafio de Projeto da DIO sobre Vibe Coding, utilizando o Lovable e o Copilot Web.

A proposta é criar um aplicativo de organização financeira pessoal baseado em interações em linguagem natural.

# Resumo do App

O aplicativo funciona como um assistente financeiro conversacional que permite registrar receitas e despesas por meio de linguagem natural. A solução busca simplificar o acompanhamento financeiro, eliminando a necessidade de planilhas ou formulários complexos e oferecendo uma experiência acessível para diferentes perfis de usuários.

# PRD refinado no Copilot Web

```markdown
PRD – App de Organização de Finanças Pessoais Conversacional com Design Universal

1. Contexto
O aplicativo será um assistente financeiro conversacional, que organiza finanças pessoais por meio de diálogos em linguagem natural. O objetivo é simplificar o controle de gastos e metas sem depender de formulários complexos ou planilhas.

2. Problema
Usuários desistem de controlar suas finanças porque os apps atuais exigem entrada manual excessiva e oferecem pouca personalização. Isso gera frustração e abandono. O app busca resolver esse problema com uma experiência fluida de conversa e recomendações automáticas.

3. Público-Alvo
- Pessoas iniciantes no controle financeiro.
- Usuários que desejam praticidade e simplicidade.
- Pessoas que preferem interações naturais em vez de interfaces tradicionais.
- Inclusão ampliada: pessoas com diferentes níveis de alfabetização digital, necessidades de acessibilidade (ex.: visão reduzida, dificuldades motoras) e preferências diversas.

4. Funcionalidades-Chave
- Registro via chat: inserir gastos e receitas em linguagem natural.
- Classificação automática: categorizar despesas sem esforço manual.
- Metas financeiras: criar e monitorar objetivos de economia.
- Agente Financeiro: recomendações personalizadas de economia.
- Relatórios simples: visualizações claras e adaptadas ao perfil do usuário.
- Design Universal: interfaces acessíveis, linguagem clara, suporte a diferentes dispositivos e opções de acessibilidade.
- Interatividade: sugestões rápidas, botões de ação e feedback dinâmico.
- Visual chamativo: cores vivas, ícones intuitivos e gráficos simples.

5. Entregável da IA (MVP)

- Principais telas:
  - Tela de boas-vindas inclusiva e chamativa.
  - Tela de chat com suporte a voz e texto, respostas dinâmicas e atalhos rápidos.
  - Tela de metas com barra de progresso animada e mensagens motivacionais.
  - Tela de relatórios com gráficos simples e alternativas textuais.
  - Tela de configurações com opções de acessibilidade e personalização.

- Recursos necessários:
  - Processamento de linguagem natural (NLP).
  - Motor de categorização automática.
  - Sistema de notificações e recomendações.
  - Recursos de acessibilidade (contraste, leitura de tela e navegação simplificada).

- Validação inicial:
  - Testes com usuários iniciantes e com necessidades diversas.
  - Feedback sobre clareza das conversas, interatividade e acessibilidade.
  - Ajustes de categorias e relatórios conforme uso real.
```

## Reflexão

## O que funcionou bem?  

O refinamento do PRD realizado no Copilot Web ajudou bastante no desenvolvimento da aplicação, especialmente porque o limite diário de créditos do Lovable é reduzido. Ter requisitos mais claros permitiu aproveitar melhor cada interação com a ferramenta.

## O que não funcionou como o esperado?  

Eu esperava conseguir realizar mais interações gratuitas no Lovable. Apesar dessa limitação, as interações disponíveis foram suficientes para compreender melhor os conceitos de Vibe Coding e explorar o potencial da plataforma.

## O que aprendeu sobre conversar com IAs?

Aprendi que conversar com uma IA é muito parecido com manter uma boa comunicação com uma pessoa. Quanto mais contexto, clareza e detalhes forem fornecidos, melhores tendem a ser os resultados gerados.
